# Project Charter

## Project Objective

The project aims to build a platform that enables industry experts to design professional, practical learning curricula that simulate real work environments, while providing learners with a structured and effective way to study modern technologies and technical skills.

### SMART Objectives

1. Develop a secure and customizable code evaluation system that supports the C programming language by the end of the MVP phase, enabling instructors to create coding-based learning experiences efficiently.
2. Build a professional and user-friendly interface for curriculum creation, browsing, and studying by the end of the MVP phase, allowing instructors and students to complete core learning and management tasks efficiently during testing.
3. Deliver a functional MVP that includes curriculum design, curriculum browsing, learning features, and code evaluation before the final presentation phase.

# Risks and Mitigation Strategies

## Risk 1: Learning New Technologies

### Mitigation Strategy

- Intensive self-learning
- Early technical research and experimentation
- Knowledge sharing among team members

## Risk 2: Maintaining Consistency Between System Components

### Mitigation Strategy

- Conduct brainstorming sessions regularly
- Build clear use cases and user stories before implementation
- Maintain consistent system architecture and documentation

---

# Success Criteria

- Users can create and study curricula successfully through the platform.
- The code evaluation system can execute and validate C programs securely.
- The MVP is completed and demonstrated successfully before the final presentation.
